# LimePackage <!-- omit in toc -->

LimePackage is collection tools for Python development. These tools are more or less thin wrappers around other packages.

# Quick start guide

Here's how you can start

## The first steps

### Installing

Install LimePackage with pip

```
pip install limepackage
```

### Importing

Import name is the same as install name, `limepackage`.

```python
import limepackage
```
